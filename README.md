## Démarrage rapide — Hackathon — Partie 2

Si vous êtes sur cette page, c'est que vous êtes dans la 2ème partie du hackathon sinon rendez vous dans le dossier `exaltemps-solidaire-practice`

1. **Récupérez le projet de votre équipe** avec la clé de contexte et le code d'équipe qui vous ont été fournis :

    ```bash
   curl -H "x-cle-contexte: $CLE" -O \
     https://pmlab-solidaire.exalt-lab.com/be/equipes/<CODE>/passation.zip
   ```

   Remplacez `$CLE` par votre clé de contexte et `<CODE>` par le code de votre équipe.

2. **Dézippez** l'archive téléchargée.
3. **À vous de jouer** : lancez les agents pour développer les features.
4. Vous pouvez builder et tester en local, mais pensez à **demander à l'agent de déployer l'app** pour qu'elle soit accessible à l'équipe sur son URL.
